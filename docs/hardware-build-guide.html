2. 面包板：先理解孔，再插零件

典型结构，不代替对你的 MB-102 做通断实测。
电源状态：完全无电

练插一根公对公杜邦线

捏塑料头垂直插入；拔出时也捏塑料头，不拉软线。弯曲的针不要硬塞。

3. ANENG 616 万用表，从表笔开始

被测物：无电

插表笔

黑表笔插 COM；你的 ANENG 616 红表笔插最下方的 INPUT 孔。不要插 10A、A、mA 或任何电流孔；本项目不测电流。

□ 黑在 COM，红在 INPUT。

AUTO 模式只测无电零件

先互碰，再测面包板

  1. 长按电源开机，保持屏幕显示 AUTO；半圆弧是屏幕图示，不是可旋转旋钮，不按 SELECT。
  2. 表笔分开显示 O.L MΩ（开路）正确；尖端互碰时约 0.3Ω 正确，蜂鸣不是必要条件。
  3. 测同一行 a–e，再测跨中沟 e–f。
  4. 测 +/− 长条的上端和下端，记录中间是否断开。

表笔互碰仍显示 O.L，或插头松动/读数无法稳定：停止并拍万用表照片。

带电时只在指定步骤测 ESP32 的低压直流：选择 V⎓，黑接 GND、红接 3V3。不要测电流，也不要接触插座。

4. ESP32 单板上电

先断电观察

找 USB-C 和丝印

寻找 USB-C、3V3、GND、GPIO4 或数字 4。看不清就停止；不要把相邻数字当 GPIO4。

可以插 USB：第一次单板上电

只接电脑，不接探头

  1. USB-C 插开发板，USB-A 插电脑。
  2. 确认电脑出现新串口。
  3. 按固件任务流烧录最小程序。

□ 正确现象：串口可见、烧录成功、重启正常。

没有串口：先换另一根数据线或电脑 USB 口；不要开始探头接线。

可选低压测量

测 3.3V

ESP32 单板上电，万用表选 V⎓。黑接已确认 GND，红接已确认 3V3，预期约 3.2–3.4V。先移开表笔，再拔 USB。

5–6. 插入面包板，建立三条总线

放一只 4.7kΩ

电阻无正反；一脚进总-DATA，另一脚进总-VCC。只能一只。通断档检查总-VCC 与总-GND不应持续蜂鸣。

11–12. 防水盒先干摆，再钻孔

📷 实物确认点 3
把 ESP32+面包板、9 个 WAGO、面板线、防水接头放在空盒旁拍俯视和四侧照片。不要先钻。PG7/M12 是名称，不等于开孔直径。
空盒、断电

干摆与逐级开孔

确认面板线内侧公头自然够到 ESP32、盒盖不压元件、WAGO 与板分区。用实物/卡尺确认螺纹，阶梯钻从小到大逐级扩孔，每一级都停下试装。清除全部塑料屑后才放回电子件。

安装仍断电

USB-C 面板线是什么

电脑或 5V USB-A 充电器 → USB-A 转 USB-C 数据线 → 盒外 USB-C 母口 → 0.3m 2.0USB-C 面板延长线 → 盒内 USB-C 公头 → ESP32

它只是把接口延到盒外，不是第二个电源。插线状态不能视为完整 IP65/IP67。

机械检查

密封、应力释放、滴水弯

防水接头夹住 RVV 外护套，不只夹散开的三芯。盒内用固定座和扎带承力；每根外线先向下形成 U 形，再向上进入盒体。所有自制接头留在盒内干燥区。

正确：线缆最低点低于进盒孔，水在 U 形最低处滴落。

错误：线从高处斜向下直接进入孔，水会沿线流向盒内；必须重新走线。

15. 最终验收清单

  • □ 黑表笔在 COM，红表笔在 INPUT，未使用 10A 口。
  • □ A、B 各自依据实物 Type A / Type B 贴好 VCC、GND、DATA。
