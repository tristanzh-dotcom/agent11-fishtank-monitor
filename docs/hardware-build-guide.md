# 第一缸 ESP32-S3 温度监控：无焊接制作手册

> 面向第一次做电子制作的人。请从第 0 章顺序执行，不要跳步。  
> 本项目只使用电脑 USB、5V USB 充电器和 ESP32 的 3.3V；不接继电器、加热棒、水泵、插排或任何 220V 控制。

## 先记住这三句话

1. 文中“断电”是指：**从 ESP32 板上拔掉 USB-C 插头**，并确认板上指示灯熄灭。
2. 除了专门测 3.3V 的步骤，插拔任何导线前都必须确认 **USB 已拔掉**。
3. 看不清板上文字、线色与本文不一致、闻到焦味、零件发热、持续蜂鸣或出现火花时，**立即停止**，拔掉 USB，拍清晰照片再继续。

## 本手册能确认什么，暂时不能确认什么

已经锁定的电气关系只有这一套：

```text
ESP32 3V3  ───── 两支探头的 VCC
ESP32 GND  ───── 两支探头的 GND
ESP32 GPIO4 ──── 两支探头的 DATA
                    │
                    └── 4.7kΩ 电阻 ── 3V3
```

下面这些物理细节必须看到你的实物照片后才能锁定，本文不会猜：

- ESP32 正反面哪个方向朝上、`3V3`、`GND`、`GPIO4` 在你手里这块板的具体位置；
- MB-102 电源长条是否在中间断开、开发板插入后两边还剩多少孔；
- KIT0021 到货的是 Type A、Type B，还是带插头/转接板的版本；
- RVV 三根内芯的实际颜色；
- ANENG 616 屏幕和按键图标的实际版本；
- 防水接头、USB-C 面板件的真实开孔直径。

每遇到“📷 实物确认点”，请先拍照，不要凭商品图继续。

## 0. 把工作区变安全

### 0.1 准备桌面

- **电源状态：**电脑可以开机，但 ESP32 暂时不接 USB。
- **拿出：**浅色干桌布、三个小盒或自封袋、纸、笔、手机。
- **动作：**擦干桌面，移走水杯、鱼缸工具、金属碎屑和 220V 插排。
- **正确结果：**桌面干燥，零件不会滚落，USB 线还未接板。
- **错误/停止：**桌面潮湿或需要在鱼缸边操作时，立即停止并换位置。
- [ ] 桌面已干燥，ESP32 未接 USB。

### 0.2 建立三个零件区

在纸上写：

- `现在使用`：主 ESP32、探头 A、探头 B；
- `备用`：第二块 ESP32、第三支探头、第十个 WAGO；
- `工具`：万用表、剥线钳、阶梯钻、扎带等。

- **正确结果：**备用件没有混入正在接线的零件。
- [ ] 三个区域已分好。

### 0.3 唯一安全断电动作

以后看到“断电”，都做同一件事：一只手扶住 ESP32，另一只手捏住 USB-C 插头的塑料/金属外壳，平直拔出；不要拉线。

- **正确结果：**USB-C 插头离开开发板，板上灯熄灭。
- **错误/停止：**插头很紧时不要左右大力摇；扶稳板后轻微水平移动再拔。
- [ ] 我知道“断电”不是关软件，而是拔掉板端 USB-C。

### 1.1 每件东西单独看一遍

1. **ESP32 主控板**：黑色长方形板，两侧是两排黑色塑料座和向下金属针，一端是 USB-C。不要把第二块备用板同时插上。
2. **MB-102 面包板**：白色塑料板，中央长沟把左右分开。它不产生电，只是把某些孔在内部连起来。
3. **KIT0021 探头**：真正入水的是不锈钢圆柱探头；线尾可能还有插头、DFR0055 小转接板和跳帽。转接板不是第二支探头，本方案暂不使用它。
4. **4.7kΩ 电阻**：细小圆柱，两端是金属脚，没有正负极。不要和其他阻值混装；从标明 `4.7K 1%` 的包装只拿一只。
5. **公对公杜邦线**：两端都有外露金属针；用于面包板孔之间。**公对母杜邦线**：一端外露针，另一端是有孔的黑色母头；可套在开发板排针上。不要凭软线颜色判断 VCC/GND/DATA。
6. **WAGO 221-413**：透明外壳、三个橙色杠杆、三个进线孔。它夹剥皮后的铜线，不夹杜邦塑料头。
7. **RVV 三芯线**：黑/白外护套里包三根绝缘内芯。它不是 USB 线，也不直接插 ESP32。
8. **两种 USB 线**：已有 USB-A 转 USB-C 数据线连接电脑/充电器到盒外；0.3m USB-C 公对母面板线穿盒壁。不要把面板线当充电器。
9. **M12/PG7 防水接头**：带压紧帽、螺纹、螺母和密封圈；它夹线缆外皮。型号名不是最终钻孔直径。
10. **ABS 防水盒**：先用一只，另一只不钻孔备用。盒子本身不保证插着 USB 时整套仍防水。
11. **ANENG 616**：有屏幕和表笔插孔的测量工具。它只用于本项目的无电通断和低压直流电压。
12. **8PK-3001D 剥线钳**：钳口有多种线径档，不是剪刀；先拿废 RVV 练习，不直接剪探头。
13. **热缩管、固定座、扎带**：热缩管套在导体拼接前才可能套入；本无焊接原型不靠热缩管制造水下接头。固定座和扎带用于承力，不负责导电。
14. **阶梯钻**：锥形、多级直径，只对空的 ABS 盒逐级扩孔；不能在装有电子件的盒子上钻。

## 2. 先理解面包板，不放 ESP32

### 2.1 一个孔不是一个独立接线柱

典型 MB-102 中间区域如下：同一数字行里，`a–e` 五孔内部相通，`f–j` 五孔内部相通；中沟把左右分开。

```text
       a b c d e       f g h i j
行 12  ●─●─●─●─●   ║   ●─●─●─●─●
                     ║
行 13  ●─●─●─●─●   ║   ●─●─●─●─●
```

外侧标有 `+`、`-` 的长条通常纵向相通，但有些 MB-102 在中间断开。颜色只是提示，不能证明导通。

### 2.2 用一根公对公杜邦线练插拔

- **电源状态：**USB 已拔掉，面包板上没有任何电源。
- **拿出：**一根两头都是金属针的公对公杜邦线。
- **动作：**捏住塑料头，垂直插入一个孔；再捏塑料头拔出。
- **正确结果：**金属针大部分进入，塑料头在板面上方，轻触不掉。
- **错误/停止：**不要捏着软线拉，不要把弯曲针硬塞。
- [ ] 已完成一次插入和拔出练习。

### 2.3 用万用表确认一根杜邦线没断

完成第 3.2 节的万用表练习后再回来：保持整根杜邦线无电，一支表笔碰一端金属针，另一支碰另一端。应显示很低电阻并可能蜂鸣；分开任意一端后应停止。若始终不通，把这根线放到“坏线/待查”区，不用于接线。

- [ ] 已验证至少一根公对公杜邦线两端导通。

## 3. ANENG 616 万用表从零开始

本章只碰没有接电的面包板、杜邦线，以及后面 ESP32 的 3.3V。不要把表笔伸进插座或插排。

### 3.1 插表笔

- **电源状态：**被测零件全部断电。
- **黑表笔：**插入标有 `COM` 的孔。
- **红表笔：**插入标有 `VΩ`、`VΩmA` 或同时含 `V` 和 `Ω` 的孔。
- **不要使用：**标有 `10A` 的孔，本项目不测大电流。
- **同样不要使用：**任何标为 `A`、`mA`、电流的插孔；本项目从不把万用表串入电路测电流。
- **正确结果：**两只插头都推到底，黑在 COM，红在 V/Ω 口。
- **错误/停止：**若正面标识和上述不同，不尝试，先拍照。
- [ ] 黑表笔在 COM，红表笔在 V/Ω 口。

### 3.2 开机和选择通断档

ANENG 616 是自动量程表，具体版本的按键图标可能不同。

1. 长按电源键开机。
2. 短按 `SELECT`，寻找蜂鸣/二极管/`Ω` 相关模式。
3. 两支金属表笔不要碰在一起时，屏幕通常显示 `OL`、很大数值或开路提示。
4. 两支金属尖端碰在一起时，应显示接近 0Ω，并可能蜂鸣。

- **正确结果：**分开不持续响，接触时数值很低并可能响。
- **错误/停止：**两笔分开仍持续响，或无法找到该模式，停止并拍表盘照片。
- [ ] 已完成表笔互碰测试。

### 3.3 验证面包板内部连接

- **电源状态：**USB 已拔掉，面包板完全无电。
- **动作 1：**两表笔插入同一数字行的 `a` 与 `e`，应导通。
- **动作 2：**改成同一行的 `e` 与 `f`，通常不导通。
- **动作 3：**测 `+` 长条的上端和下端，再测 `-` 长条上端和下端。
- **记录：**若中间不通，在断点处贴纸标“断”。
- **停止条件：**你的实测与上述典型结构不同，不代表坏；先画下实际结果，后续按实测使用。
- [ ] 已画出这块 MB-102 的真实导通范围。

### 3.4 稍后如何测 3.3V

只有第 4.3 节会带电测电压。届时选择直流电压模式，通常用 `V⎓` 表示；黑表笔碰 GND，红表笔碰 3V3。不要让两支金属尖端互相碰到，也不要跨到相邻针脚。

## 4. 只给 ESP32 上电，不接其他零件

### 4.1 上电前观察

- **电源状态：**USB 已拔掉。
- **动作：**把主用 ESP32 放在不导电桌面，找到板上 USB-C 口；观察两侧丝印是否能找到 `3V3`、`GND`、数字 `4` 或 `GPIO4`。
- **不要做：**现在不要插面包板，不要接探头。
- **停止条件：**看不清字或同时看到多个可能的 `4`，先拍照。
- [ ] 已找到 USB-C 口，三个目标丝印待照片确认。

### 4.2 电脑识别

1. 拿出已有 USB-A 转 USB-C **数据线**。
2. USB-C 插 ESP32，USB-A 插电脑。
3. 板上可能亮灯；电脑应出现新串口。
4. 按固件任务流烧录“串口/板卡最小测试”。本硬件手册不替代固件说明。

- **正确结果：**电脑出现串口，能够烧录并重新启动。
- **错误/停止：**没有串口时，先换第二根已知可传数据的线或另一个电脑 USB 口；不要开始探头接线。
- [ ] 主板已被电脑识别并能烧录。

### 4.3 认识 3.3V 测量（可选但推荐）

- **电源状态：**ESP32 通过电脑 USB 上电；板上仍没有其他线。
- **万用表：**黑表笔仍在 COM，红表笔仍在 V/Ω 口，选择直流电压 `V⎓`。
- **动作：**只握绝缘手柄；黑尖端接已确认的 GND，红尖端接已确认的 3V3。
- **正确结果：**约 3.2–3.4V。若显示约 -3.3V，说明两表笔角色反了。
- **立即停止：**显示接近 5V、数值乱跳、表笔可能同时碰到两个针脚。
- **结束：**先移开表笔，再拔 ESP32 的 USB-C。
- [ ] 已记录实测 3V3：________ V；或已选择跳过并等待照片确认。

## 5. 把 ESP32 放到面包板上

### 📷 实物确认点 2

请先把 ESP32 横跨 MB-102 中沟“轻放但不压入”，从正上方拍照。必须看到两排针与面包板孔。确认能插下并且至少留有可用孔后再执行。

### 5.1 压入

- **电源状态：**USB 已拔掉。
- **方向：**两排黑色针脚分别位于中沟两侧，不能落在同一侧五孔组里。
- **动作：**先对齐所有针，再用两侧均匀的小力垂直压入；不要只压 USB 口一端。
- **正确结果：**所有针进入孔中，板大致水平，没有针折弯。
- **错误/停止：**孔距不合、板完全遮住所有可用孔或任一针弯曲时，不硬压。改用公对母杜邦线把板移到面包板旁边，但必须先依据照片给出逐针方案。
- [ ] ESP32 已平稳插入，或已停止等待替代接法。

## 6. 先建三条总线，再放电阻

为了避免“红线就是电源”这种猜测，本项目对节点和线缆都贴文字标签。

### 6.1 建立总节点

- **电源状态：**USB 已拔掉。
- **准备标签：**`总-VCC`、`总-GND`、`总-DATA`。
- **杜邦端头：**如果 ESP32 已插入面包板，使用公对公线；如果照片确认需要把板放在面包板旁，才使用“母头套开发板排针、公头进面包板”的公对母线。
- **动作：**从已确认的 ESP32 `3V3`、`GND`、`GPIO4` 各引出一根短杜邦线，分别插到三个互不相通的面包板行。
- **必须记录：**在纸上写每个节点所用的具体行号/孔位；没有实物照片确认前，本手册不替你填写行号。

| 标签 | ESP32 起点 | 面包板实际位置（你填写） |
|---|---|---|
| 总-VCC | `3V3` | __________ |
| 总-GND | `GND` | __________ |
| 总-DATA | `GPIO4` | __________ |

- **正确结果：**三个标签贴在三组不同节点旁。
- **错误/停止：**任意两根线落在同一内部相通行，拔掉重来。
- [ ] 三个总节点已建立并记录。

### 6.2 放一只 4.7kΩ 电阻

- **电源状态：**USB 已拔掉。
- **拿出：**一只 4.7kΩ 1/4W 金属膜电阻。方向不分正反。
- **动作：**一只脚插入 `总-DATA` 节点，另一只脚插入 `总-VCC` 节点。
- **不要做：**不要把两只脚插进同一行；不要再加第二只电阻。
- **正确结果：**电阻跨在 DATA 与 3.3V 之间，两脚不互碰。
- [ ] DATA 与 3V3 之间只有一只 4.7kΩ 电阻。

### 6.3 无电短路检查

- **电源状态：**再次确认 USB 已拔掉。
- **万用表：**通断档。
- **动作：**测 `总-VCC` 与 `总-GND`。
- **正确结果：**不应持续蜂鸣。开发板电容可能造成短暂数值变化，以“不持续”为准。
- **停止条件：**持续蜂鸣，不要接 USB；逐根拔下刚接的线，检查是否串行。
- [ ] VCC 与 GND 未出现持续蜂鸣。

## 7. 接第一支 KIT0021：探头 A

### 7.1 先判定 Type A 或 Type B

DFRobot 官方给出两种三线定义：

| 到货类型 | VCC | GND | DATA |
|---|---|---|---|
| Type A | 红 | 黑 | 黄 |
| Type B | 红 | 黄 | 绿 |

这张表只有在实物标签、说明书或 DFRobot 原装线序能确认类型时才可用。不要仅凭“常见颜色”判断。

- 若是 Type A：贴 `A-VCC` 在红线、`A-GND` 在黑线、`A-DATA` 在黄线。
- 若是 Type B：贴 `A-VCC` 在红线、`A-GND` 在黄线、`A-DATA` 在绿线。
- 若线端带不可识别的插头、颜色不同或卖家标签矛盾：立即停止，不剪线，拍照。

### 7.2 不使用随附转接板的提醒

## 10. 用 RVV 延长并布置 9 个 WAGO

只有探头原线不够长时才执行。先量真实路径，包含滴水弯和 10–20cm 维修余量；不要把 5m 直接平均切半。

| RVV 实际颜色 | 被你指定的角色 |
|---|---|
| ______ | VCC |
| ______ | GND |
| ______ | DATA |

- [ ] 两段 RVV 的两端都已贴 VCC/GND/DATA 标签。

### 10.2 9 个 WAGO 的固定命名

把九个工作 WAGO 逐个贴上：

```text
探头 A 端：A-VCC  A-GND  A-DATA
探头 B 端：B-VCC  B-GND  B-DATA
控制盒端：总-VCC 总-GND 总-DATA
```

**第十个 WAGO** 保持未使用，放进备用袋。

把九个 WAGO 按下面逐号完成；“空”表示该孔不放任何东西、杠杆压平：

| 编号/标签 | 孔 1 | 孔 2 | 孔 3 |
|---|---|---|---|
| 1 `A-VCC` | 探头 A VCC | A-RVV VCC | 空 |
| 2 `A-GND` | 探头 A GND | A-RVV GND | 空 |
| 3 `A-DATA` | 探头 A DATA | A-RVV DATA | 空 |
| 4 `B-VCC` | 探头 B VCC | B-RVV VCC | 空 |
| 5 `B-GND` | 探头 B GND | B-RVV GND | 空 |
| 6 `B-DATA` | 探头 B DATA | B-RVV DATA | 空 |
| 7 `总-VCC` | A-RVV VCC | B-RVV VCC | 去面包板总-VCC |
| 8 `总-GND` | A-RVV GND | B-RVV GND | 去面包板总-GND |
| 9 `总-DATA` | A-RVV DATA | B-RVV DATA | 去面包板总-DATA |

一次只完成一个编号，完成后在表的该行旁打勾，再拿下一个 WAGO。

### 10.3 A 端三个拼接

- `A-VCC` WAGO：探头 A 的 VCC + A 段 RVV 的 VCC；第三孔空。
- `A-GND` WAGO：探头 A 的 GND + A 段 RVV 的 GND；第三孔空。
- `A-DATA` WAGO：探头 A 的 DATA + A 段 RVV 的 DATA；第三孔空。

每接一根都执行“掀杠杆—插到底—压平—透明壳观察—轻拉”。空孔的杠杆也压平。

### 10.4 B 端三个拼接

按完全相同方法连接 `B-VCC`、`B-GND`、`B-DATA`。不要交叉到 A 段 RVV。

### 10.5 控制盒端三个汇合

每个总 WAGO 正好用满三个孔：

- `总-VCC`：A 段 RVV VCC + B 段 RVV VCC + 去面包板 `总-VCC` 的短线；
- `总-GND`：A 段 RVV GND + B 段 RVV GND + 去面包板 `总-GND` 的短线；
- `总-DATA`：A 段 RVV DATA + B 段 RVV DATA + 去面包板 `总-DATA` 的短线。

> WAGO 夹的是剥皮铜导体；杜邦线塑料母头不能塞进 WAGO。去面包板的短线必须一端是适合 WAGO 的裸多股线，另一端是适合面包板的公针成品线。若手头没有这种安全过渡线，立即停止并拍照，不要剪开随机杜邦线后硬夹极细铜丝。

### 10.6 无电逐线检查

- **电源状态：**USB 已拔掉。
- 用通断档依次确认 A-VCC 只到总-VCC、A-GND 只到总-GND、A-DATA 只到总-DATA；再检查 B 三线。
- 再确认总-VCC 与总-GND 不持续导通。
- [ ] 六条延长芯线均到正确总节点，VCC/GND 无持续短路。

## 12. 安装 USB-C 面板口、进线和滴水弯

### 12.1 USB-C 面板线的作用

它不是第二个电源，也不是转换器。它只是把 ESP32 原本藏在盒内的 USB-C 口延长到盒外：

```text
电脑或 5V USB-A 充电器
  → 已有 USB-A 转 USB-C 数据线
  → 盒外 USB-C 母口
  → 面板延长线（穿过盒壁）
  → 盒内 USB-C 公头
  → ESP32
```

这样以后刷机、看串口或供电时不必开盒。防尘盖只在没有插线时起保护作用；插线状态不等于整套仍有 IP65/IP67。

### 12.2 安装顺序

1. 断电，盒外没有 USB 线。
2. 把面板件密封圈贴盒外壁或按其结构安装，螺母在内侧锁紧。
3. 两根 RVV 分别穿过防水接头；外护套应落在压紧密封区，不能只夹三根散开的内芯。
4. 盒内公头插 ESP32；不要用线缆悬吊开发板。
5. 用固定座和扎带做应力释放，扎带不勒伤线皮。
6. 所有外来线先向下形成 U 形滴水弯，再向上进入盒体。

**正确：**线缆最低点低于进盒孔，水会在 U 形最低处滴落。**错误：**线从高处斜向下直接进入孔，雨水/缸水会沿线流向盒内；看到这种路径就重新走线。

- [ ] 面板线和两根 RVV 均有独立应力释放。
- [ ] 所有进线都有滴水弯，自制接头全部在干燥盒内。
