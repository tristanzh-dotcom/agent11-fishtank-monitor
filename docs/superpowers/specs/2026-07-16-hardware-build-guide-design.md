# 第一缸温度监控零基础制作手册设计

## 目标与读者

为完全没有电子装配经验、已经忘记万用表使用方法的读者，制作一套可以在电脑端逐步照做的中文手册。读者不需要预先理解面包板、电阻、GPIO、OneWire、WAGO、通断档或直流电压档。

手册必须从“桌面上摆着一堆刚拆包零件”的状态开始，每一步只要求完成一个明确动作，并告诉读者：拿哪个零件、识别哪一面、使用哪根线、连接到哪里、完成后应看到什么、出现什么情况必须停止。

手册只覆盖 USB 5V 和开发板 3.3V 低压侧。它不包含继电器、SSR、加热棒控制、水泵控制、插排接线、漏电保护器操作或任何 220V 测量与制作。

## 权威硬件合同

硬件型号、数量和安全边界以 `HANDOVER_HARDWARE_20260716.md` 为准：

- Waveshare `ESP32-S3-DEV-KIT-N16R8-M` ×2。
- DFRobot `KIT0021` ×3；安装两支，第三支备用。
- MB-102 830 孔面包板 ×1。
- 4.7kΩ、1/4W 金属膜电阻包 ×1。
- 2.54mm、20cm、40P 三排杜邦线套装 ×1。
- WAGO `221-413` ×10。
- RVV 三芯 0.3平方 ×5m。
- `2.0USB-C` 公对母 0.3m 面板数据线 ×1。
- 约 200×120×75mm IP65/IP67 ABS 盒 ×2。
- M12/PG7 防水接头 ×10。
- ANENG `616` 万用表 ×1。
- Pro'sKit `8PK-3001D` 剥线钳 ×1。
- 用户已有 USB-A 5V 2A 以上充电器、USB-A 转 USB-C 数据线两根、探头固定件和 3M 固定胶。

固定电气合同为：两支已安装探头采用三线非寄生供电；VCC 并联到 `3V3`，GND 并联到 `GND`，DATA 并联到 `GPIO4`；DATA 与 3V3 之间仅使用一个外置 4.7kΩ 上拉电阻。DFRobot DFR0055 转接板及其上拉跳帽不接入这套 WAGO 原型。

## 手册结构

### 第 0 章：先不要接线

- 明确只操作 USB 5V/3.3V 低压侧。
- 解释“断电”在本项目中就是拔掉 ESP32 上的 USB-C 插头。
- 建立三类醒目标记：可以继续、现在断电、立即停止并拍照求助。
- 要求桌面干燥、无金属碎屑、无水杯，鱼缸和 220V 插排不在操作区。

### 第 1 章：一个零件一个零件认识

每件物料单独一张识别卡，包含：中文名称、包装名称、外形、正反面、数量、当前步骤是否使用、容易拿错的相似物。

必须覆盖 ESP32-S3、MB-102、KIT0021 探头及其随附件、4.7kΩ 电阻、四种杜邦线端头、WAGO 221-413、RVV 三芯线、USB 数据线、USB-C 面板线、M12/PG7、ABS 盒、ANENG 616、8PK-3001D、热缩管、扎带座和阶梯钻。

### 第 2 章：三分钟认识电路关系

- 用“同一排孔相当于内部已经连在一起”的图解释面包板，不要求读者先理解电路图。
- 明确 MB-102 中央沟槽两侧不相通；A-E 同编号孔相通，F-J 同编号孔相通。
- 供电轨可能在中间断开，必须实测，不根据红蓝印刷线猜测。
- 用红色表示 VCC 功能、黑色表示 GND 功能、黄色表示 DATA 功能；图示颜色表示功能，不代表到货探头必然采用该颜色。
- 用图说明“并联”和“4.7kΩ 上拉”，但操作步骤仍用具体插孔和线名描述。

### 第 3 章：ANENG 616 从零开始

- 标明黑表笔插 `COM`，红表笔插电压/电阻/通断对应插孔；不得插电流测量孔。
- 讲清旋钮的关机、通断/蜂鸣和直流电压位置；具体图标和按键名称必须根据用户实物正面照片或 ANENG 616 官方说明核对。
- 先用两支表笔互碰练习蜂鸣，再测一条杜邦线通断，再测面包板同排孔和中央沟槽两侧。
- 测直流 3.3V 时明确黑表笔接 GND、红表笔接 3V3；反接只会显示负号的说明必须以该表工作方式核对后写入。
- 每个万用表步骤重复“本手册禁止测墙插、插排、加热棒和任何 220V”。

### 第 4 章：ESP32 单板首次上电

- 先不插面包板、不接探头。
- 找到板上的 USB-C 口、BOOT、RESET、3V3、GND、GPIO4 丝印。
- 使用 USB-A 转 USB-C 数据线连接电脑，记录预期串口现象。
- 串口不存在、反复连接/断开或板子异常发热时立即拔线并停止。

### 第 5 章：把 ESP32 插到 MB-102

- 以用户实物照片为依据生成俯视图，标明 USB-C 朝向、中央沟槽、左右排针和预留孔。
- 在没有用户实物照片前，不写“第几行第几列”的虚构孔位。
- 逐边垂直压入，确认两排针脚没有落在同一组相通孔中，也没有针脚悬空或弯折。
- 设置拍照确认点：插板完成但未接 USB 时拍俯视照片。

### 第 6 章：第一次搭三条低压节点

- 用三根选定颜色的公对公杜邦线分别从 ESP32 的 3V3、GND、GPIO4 引到独立面包板节点。
- 每根线单独完成；上一根核对无误才拿下一根。
- 解释杜邦线的“公头”是露出金属针的一端，“母头”是带孔的一端；根据实际板上排针决定使用公对母或公对公，不只按套装名称猜。
- 放置唯一的一只 4.7kΩ 电阻：一脚到 DATA 节点，另一脚到 3V3 节点；电阻无方向，不区分正负。
- 上电前用万用表确认 3V3 与 GND 不短路，并给出“蜂鸣/阻值显示”对应的继续或停止规则。

### 第 7 章：只接第一支 KIT0021

- 先按到货标签选择 Type A 或 Type B：Type A 为红 VCC、黑 GND、黄 DATA；Type B 为红 VCC、黄 GND、绿 DATA。
- 把不适用的线序折叠或明显标为“不要照这一栏接”。
- 每根探头线到对应节点单独画图，禁止使用“按常规接线”等省略语。
- 通电后显示串口识别一支探头和合理温度的预期现象。
- 设置拍照确认点：第一支探头接好、仍未通电时拍俯视照片。

### 第 8 章：接第二支、记录 ROM 和校准

- 断开 USB 后，把第二支探头按相同功能并联到同一三条节点。
- 明确不增加第二只 4.7kΩ 电阻。
- 解释 ROM 地址是每支探头的“身份证号码”；逐只断开以确认主缸/底滤角色。
- 两支探头与独立温度计同杯静置 15 分钟，使用可填写的记录表。
- 桌面运行至少 2 小时，提供 0、15、30、60、120 分钟记录格和停止条件。

### 第 9 章：认识并练习 WAGO 与剥线钳

- 先用 RVV 余料练习，不直接剪探头线。
- 解释 0.3平方是每芯铜导体截面积，不是外径。
- 用 8PK-3001D 的 0.6mm 档位在余料试剥；若铜丝被切断，改用更大档位并重新试验。
- WAGO 按官方顺序：以外壳标尺确认约 11mm 剥线，抬起橙色杆、插到底、压平、从透明壳检查、轻拉确认。
- 探头内芯必须单独试夹；若夹不牢、铜丝外露或低于 WAGO 规格，立即停止并拍照，不能硬塞或焊接。

### 第 10 章：RVV 延长与九个 WAGO 的编号

- 不预先把 5m RVV 平分；先实测两条走线并各留滴水弯和维修余量。
- 给九个 WAGO 贴标签：A-VCC、A-GND、A-DATA、B-VCC、B-GND、B-DATA、总-VCC、总-GND、总-DATA；第十个 WAGO 备用。
- 用逐根导线表列出每个 WAGO 的三个孔分别插什么；第三孔不使用时明确写“留空”。
- 每完成一个 WAGO 就做轻拉检查和可选的万用表通断检查。
- 所有拼接必须位于干燥盒内或干燥位置，绝不入水。

### 第 11 章：接线盒布局和开孔

- 开孔前先将 ESP32、面包板、WAGO、USB-C 面板线和防水接头在盒内干摆。
- 用俯视布局图标出建议区域，但实孔位置必须由用户到货实物照片和尺寸确认。
- 解释阶梯钻每一级的含义；要求夹稳空盒、戴护目镜、内部无电子元件时才开孔。
- 每钻一级停下试装，不一次钻到最大孔径。
- 设置不可逆操作确认点：用户发盒体布局和孔位标记照片，确认后再钻。

### 第 12 章：USB-C 面板线、滴水弯和装盒

- 说明盒内公头接 ESP32、盒外母口接现有 USB-A 转 USB-C 数据线。
- 面板盖只在未插线时防尘；不把它描述为可浸水接口。
- 每条入盒线画正确滴水弯与错误直线入盒对照图。
- 用扎带座实现应力释放，不能让外部拉力直接作用于 ESP32 USB-C 口或面包板。

### 第 13 章：下缸与 48–72 小时观察

- 主缸探头为报警依据；放中下层稳定水流区，避开加热棒、直冲水流、缸壁和底砂。
- 底滤探头只作诊断；放回水泵/回水仓，避开加热棒和泵体。
- 使用已有固定件防止被鱼啃咬、拉扯或被泵吸入。
- 不通过关闭加热棒、停泵或人为升降温测试报警。
- 提供 48–72 小时观察表和异常处理分支。

### 第 14 章：视频学习清单

视频只作视觉补充，手册仍须独立完整。清单至少覆盖：

- 面包板内部连接方式。
- 数字万用表的通断与低压直流电压测量。
- WAGO 221 抬杆、剥线、插线、压杆和轻拉检查。
- ESP32 连接电脑、识别串口和烧录。
- DS18B20 三线接法、4.7kΩ 上拉和多探头 OneWire。

每个链接必须在生成时实际打开核对标题、频道和内容；在手册中写明推荐观看的主题、与本项目不同之处，以及“不要照视频操作市电”的提示。优先采用官方厂家、教育机构或长期稳定的电子教学频道；不以视频内容覆盖本项目的 GPIO4、3.3V、KIT0021 线序和安全合同。

## 每一步的固定模板

每个操作步骤必须包含以下字段：

1. **此刻是否断电**：明确写“USB 已拔掉”或“现在可以插 USB”。
2. **拿什么**：零件全名、数量和识别特征。
3. **为什么做**：一句普通语言解释。
4. **怎么拿/朝向**：正面、背面、USB 口朝向、金属端/塑料端。
5. **做一个动作**：不在一个编号中隐藏多个动作。
6. **正确现象**：读者能肉眼、串口或万用表确认的结果。
7. **错误现象**：列出最常见的 1–3 种错误。
8. **停止条件**：明确何时拔 USB、不要继续并拍照求助。
9. **完成勾选**：提供复选框。

## 验收标准

- 零电子经验读者无需查其他资料即可完成桌面单探头和双探头低压接线。
- 每个实际接线动作均明确断电状态、零件、方向、端点、正确现象和停止条件。
- 万用表章节从表笔插孔和互碰蜂鸣开始；绝不引导用户测量市电。
- DFRobot Type A/Type B 线序分支清晰，不会同时要求两种线序。
- 两支探头并联且全系统仅一个外置 4.7kΩ 上拉。
- 九个 WAGO 的编号、每孔导体和第十个备用端子明确。
- 15 分钟校准、2 小时桌面运行和 48–72 小时观察均有可填写表格。
- HTML 单文件离线打开，Markdown 与 HTML 的安全规则和接线合同一致。
- 视频链接在交付时可打开且已写明与本项目的差异；视频不是执行依据。

## 实物照片门槛

在写入最终精确孔位、万用表旋钮位置和不可逆开孔位置前，需要用户提供：

- ESP32-S3 正面和背面清晰照片，能看清两侧丝印。
- MB-102 正面俯视照片，能看清行列编号和电源轨断点。
- KIT0021 包装/说明中的线序标签和三根裸线照片。
- ANENG 616 正面照片，能看清插孔、旋钮和按键。
- ABS 盒、M12/PG7、USB-C 面板件的实物与尺寸照片。

在照片未齐时，可以完成零件识别、基础知识、通用操作和带“实物确认”标记的草稿；不得把草稿中的示意位置描述为最终一对一孔位。
