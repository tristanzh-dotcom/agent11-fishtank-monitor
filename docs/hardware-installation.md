# 第一缸硬件安装与上电流程

本流程保留既有主缸与回水缸双探头的低压接入要求：微雪 `ESP32-S3-DEV-KIT-N16R8-M`、DFRobot `KIT0021`、WAGO `221-413`、RVV 三芯 0.3平方延长线、单个 4.7kΩ 上拉，以及 `2.0USB-C` 公对母面板数据线。不接继电器、SSR、加热棒、回水泵或任何 220V 控制。

新增老四缸、小黑缸、毛毛缸前，先按 [五探头接入清单](five-probe-commissioning.md) 核对物料、记录五个 ROM 并完成干态验证。三个新增探头仍与现有两支共用 `GPIO4`、`3V3`、`GND` 和同一只 4.7kΩ 上拉，不按 OneWire 发现顺序绑定角色。

## 到货验收与无电检查

1. 清点 2 块 ESP32-S3、3 套 DFRobot KIT0021、10 个 WAGO 221-413、5m RVV 三芯 0.3平方、2 个 ABS 盒、10 个 M12/PG7 接头，以及 USB-C 面板线。
2. DFRobot KIT0021 的官方线序可能是 Type A（红 VCC、黑 GND、黄 DATA）或 Type B（红 VCC、黄 GND、绿 DATA）。对照实物包装/说明确认后再接线。
3. KIT0021 附带的 DFR0055 转接板有上拉跳帽。当前 WAGO 原型使用外置 4.7kΩ 电阻，故不要把 DFR0055 接入总线，避免出现重复上拉。
4. RVV 0.3平方表示每芯截面积 0.3mm²。使用 8PK-3001D 时先在 0.6mm 档位对余料试剥；铜丝被割伤时停止并改用更大档位。
5. 仅在无电状态下试夹探头细线。WAGO 221-413 对细绞线的额定下限为 0.14mm²；若探头线夹不牢或铜丝外露，不得强行使用 WAGO。

## 桌面接线（先不延长、不装盒）

1. 用现有 USB-A 转 USB-C 数据线把 ESP32-S3 直接接电脑，确认串口和烧录正常。
2. 将开发板插到 MB-102 面包板，建立三条低压节点：`3V3`、`GND`、`GPIO4`。
3. 将一只 4.7kΩ、1/4W 金属膜电阻接在 `GPIO4` 与 `3V3` 之间。
4. 接第一支 KIT0021：VCC 到 `3V3`、GND 到 `GND`、DATA 到 `GPIO4`。上电前用 ANENG 616 确认 `3V3` 与 `GND` 不短路；它不用于任何市电测量。
5. 烧录/运行探头扫描程序，记录第一支 ROM 地址和读数。
6. 按同一线序接第二支 KIT0021 到相同三条节点。两支探头并联，**不增加第二只 4.7kΩ 电阻**。
7. 再次扫描，确认恰好识别两支探头并记录各自 ROM。通过逐只断开来绑定“主缸”与“底滤”物理角色；随后将 ROM 分别写入 `include/config.hpp` 的 `main_tank_sensor` 与 `sump_return_sensor`，不再依赖发现顺序。

## 延长、WAGO 与防水盒

1. 先量实际走线，再裁 RVV。不要让拼接点处于水面下、底柜积水区或滴水路径中。
2. 每支需要延长的探头，用 3 个 WAGO 分别拼接 VCC、GND、DATA；每个 WAGO 只混接同一种功能导体。控制盒端再用 3 个 WAGO 分别汇合两支探头的 RVV 芯线与到面包板的短杜邦线。
3. 所有 WAGO 必须位于干燥的 ABS 盒内。压下杠杆后应能从透明壳看见插入到位的导体；轻拉每根线，不得松动。
4. 防水接头、USB-C 面板件到货后先量安装孔径，再用阶梯钻逐级开孔。探头线经 M12/PG7 入盒；`2.0USB-C` 公对母面板线的内部公头插 ESP32，外部母口供 USB-A 转 USB-C 数据线插入。
5. 外部 USB-A 5V 2A 以上充电器只给低压盒供电。面板防尘盖仅在未插线时盖上；整个装置仍须放在底柜外侧干燥位置。

## 安装位置与验证

1. `main_tank_sensor` 探头固定在主缸中下层、稳定水流区，离加热棒、直冲出水、缸壁和底砂至少 10cm；它是安全报警依据。
2. `sump_return_sensor` 探头固定在回水泵/回水仓，离加热棒和泵体至少 10cm；它只用于循环诊断。
3. 两支探头与独立温度计在同杯或同一稳定水流中静置 15 分钟，记录偏差；异常探头不下缸。
4. 桌面连续运行至少 2 小时，确认无重启、读数稳定、线缆/接头无异常发热。
5. 下缸后只监控运行 48–72 小时。核对主缸读数与独立温度计；夏季稳定 26–27°C 不应误报警。

任何涉及插排、加热棒、漏电保护器或其他 220V 设备的改动都不属于本流程。
